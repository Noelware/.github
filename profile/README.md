## Libraries
- [🌺💜 **`Violet`**](https://docs.noelware.org/library/cpp/violet) [C++]: Extended standard library for C++
- [🧶 **`remi`**](https://docs.noelware.org/library/java/remi) [Java]: Robust, simple Java 21 library to handle object storage communication
- [🧶 **`remi-rs`**](https://docs.rs/remi) [Rust]: Robust, simple, and async Rust library to handle object storage communication
- [🪚 **`Azalia`**](https://docs.rs/azalia) [Rust]: Family of crates to help aid development of Noelware's Rust projects
